Forgot your locked Notes password on iPhone? What you can do

If you forget the password for a locked note, Apple cannot recover it. You still have three things to try, and one thing a reset will not do.

1. Try Face ID or Touch ID

If you turned on Face ID or Touch ID for Notes, it opens the note without the password. Tap the note and look at the phone.

2. Check whether the note uses your passcode

A note locks with either a separate password or your iPhone passcode. If you chose that, the passcode opens it. On a new iPhone, it can ask for the old iPhone's passcode.

3. Reset the password, with a catch

Open Settings, then Apps, then Notes, then Password, and choose Reset Password. It asks for your Apple Account password. A reset sets a new password for new notes only. Notes locked with the old password stay locked, and you need the old password to open them.

If you cannot open a note

You can delete it without opening it. Swipe the note in the list and delete it. It goes to Recently Deleted for 30 days, then it is gone for good.

For next time

Write the password in a safe place, or use your iPhone passcode and Face ID so there is nothing separate to forget.

Common questions

What can I do if I forget my locked Notes password?

If Face ID or Touch ID is set up for Notes, use it to open the note. You can also reset the Notes password under Settings, Apps, Notes, Password. A reset does not open notes locked with the old password.

Can you delete a locked note if you forgot the password?

Yes. You can delete a locked note without opening it. You cannot read it, and the deletion cannot be undone once it is removed from Recently Deleted.

How do I remove the Notes lock on iPhone?

Open the locked note, open its menu, and choose Remove. You need the password, or Face ID or Touch ID, to do it.
